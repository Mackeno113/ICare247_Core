Luồng Form Runtime (end-to-end) — /form/{FormCode}

Render → tương tác → submit. Nơi 3 engine chạy: Metadata · Validation · Event. 8 pha:

Pha 1 Load Form Metadata

User navigate /form/sys_UI_Design
FE FormRunner.OnInitializedAsync()
FormApiService.GetFormAsync(code, lang=vi, platform=web)
FE → GET /api/v1/config/forms/sys_UI_Design?lang=vi&platform=web · header X-Tenant-Id: 1
FormController.GetByCode() → GetFormByCodeQuery (MediatR)
Api App
FormRepository.GetByCodeAsync()
Infra Config DB — SELECT Ui_Form · Ui_Tab/Ui_Section · Ui_Field (JOIN Sys_Column → Column_Code AS FieldCode) · Ui_Field_Lookup (nếu dynamic) · Sys_Resource (i18n)
Response FormMetadataDto → build FieldState[]
FE NormalizeFieldType(): TextBox→text · Memo→textarea · CheckBox→bool · ComboBox+dynamic→combobox · LookupBox→fklookup …

Pha 2 Batch load static lookup options

LookupApiService.GetOptionsBatchAsync(["GENDER", …])
FE Check in-memory cache: HIT → dùng ngay · MISS → gọi API song song (Task.WhenAll)
GET /api/v1/lookups/GENDER?lang=vi → LookupController.GetByCode()
DB SELECT Sys_Lookup_Item WHERE Lookup_Code=@Code AND Tenant_Id=@TenantId ORDER BY Sort_Order
cache[code] = options → State.Options

Pha 3 FORM_LOAD event (Rules Engine)

FormRunner.FireEventAsync("FORM_LOAD", null)
FE → POST /api/v1/forms/sys_UI_Design/handle-event { eventType, contextSnapshot }
RuntimeController.HandleEvent()

EventRepository.GetByTriggerAsync(formId, "FORM_LOAD", …)
Infra SELECT Evt_Definition ⋈ Ui_Field ⋈ Sys_Column WHERE Trigger_Code=@…
Evaluate ConditionExpr (AST) → Execute Evt_Action[] theo Order_No
Trả UiDeltaDto[]: SET_VALUE · SET_VISIBLE · SET_REQUIRED · SET_READONLY · RELOAD_OPTIONS
FormRunner.ApplyDeltas(deltas)
FE áp delta vào FieldState

Pha 5 Dynamic lookup data (combobox / fklookup)

Trigger: OnParametersSet lần đầu, hoặc ReloadTriggerField đổi
LookupQueryService.QueryAsync(fieldId, Context)
FE → POST /api/v1/lookups/query-dynamic { fieldId, contextValues }
DynamicLookupRepository.QueryAsync() — 4 bước an toàn
Infra ① đọc cấu hình Ui_Field_Lookup (verify tenant) → ② validate identifiers (regex) → ③ build safe SQL (BuildSelectColumns) → ④ execute Dapper params (@TenantId + contextValues sanitized, không concat SQL)
State.DynamicRows = rows → re-render dropdown / popup grid

Pha 6–7 Field changed & Field blur

Change: Renderer OnChange(fieldCode, newValue) → FormRunner.OnFieldChanged
set State.Value, clear errors, cập nhật Context → FireEventAsync("FIELD_CHANGED", fieldCode) → EventEngine → UiDelta (VD cascade PhongBanID → reload NhanVienID)
Blur: Renderer OnBlur(fieldCode) → ValidateFieldAsync
App → POST /validate-field → ValidationEngine.ValidateFieldAsync: load rule của field → AST evaluate → trả List<ValidationError> → hiển thị badge lỗi dưới field

Pha 8 Submit & Validate toàn form

Click “Submit & Validate” → ValidateFormAsync(contextSnapshot)
FE → POST /api/v1/forms/…/validate
ValidationEngine.ValidateFormAsync()
App Load TẤT CẢ rule → topological sort (dependency order) → evaluate → trả Dictionary<fieldCode, List<ValidationError>>
Có lỗi → focus field lỗi đầu tiên · Sạch → success / gọi save API
Payload Lưu gồm mọi field IsVisible — chỉ loại field ẩn, không loại read-only. (memory: Form Save Payload = Visible)
Breakpoint chính
RuntimeController.ValidateField/HandleEvent (formCode, body, tenant) → MetadataEngine.GetFormMetadataAsync (null? cache hit?) → ValidationEngine/EventEngine (rule nào chạy, kết quả AST) → AstEngine nếu nghi sai biểu thức.

Auth · Refresh & Logout

POST /api/v1/auth/refresh — rotation

Access token hết hạn → dùng refresh token xin cặp mới. Token cũ bị thu hồi, cấp token mới.

AuthController.Refresh → RefreshTokenCommand
HashRefreshToken(raw) → SHA-256 → GetByHashAsync
null / DaThuHoi / HetHan≤now → 401 Phiên không hợp lệ
GetByIdAsync (user còn HoatDong?) → RevokeAsync token cũ
rotation — token cũ set DaThuHoi=1
Create access + refresh mới → InsertAsync

POST /api/v1/auth/logout — 204 idempotent

Thu hồi refresh token phiên hiện tại. Access token (JWT) không thu hồi được — tự hết hạn (stateless). FE xóa token cục bộ.

Đá mọi phiên ngay? gọi RefreshTokenRepository.RevokeAllForUserAsync (đã có, chưa expose endpoint).
Lỗi hay gặp: 401 ngay lần refresh đầu → FE gọi refresh 2 lần song song (token đã rotate), hoặc gửi token gốc đã hết hạn. Kiểm HetHanUtc (7 ngày, 30 nếu RememberMe).

CRUD sinh động từ metadata. Bảng đích đọc ở server theo formCode — client không gửi tên bảng. Body key = Field_Code (= tên cột DB).

Quy tắc bảo mật (tóm tắt)

  1. Tenant isolation: mọi query filter Sys_Table.Tenant_Id = @TenantId.
  2. SQL injection: SourceName / column names qua SafeIdentifierRegex (^[a-zA-Z_][a-zA-Z0-9_.]*$); FilterSql/OrderBy block DDL/DML keyword; ContextValues → Dapper params (KHÔNG concat vào SQL).
  3. Cross-tenant: DynamicLookupRepository verify tenant qua chuỗi Ui_Field_Lookup → Ui_Field → Ui_Form → Sys_Table → Tenant_Id.
  4. TenantId override: contextValues không được override param @TenantId.
